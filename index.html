Fundamentos de IA Generativa
LLMs embeddings tokenização grátis disponível

📝 Anotações
  • A barreira de entrada para construir software caiu muito. O que costava meses e uma equipe hoje é questão de dias — às vezes horas. Isso não é exagero, é o que vivi.
  • A diferença vai continuar sendo quem sabe o que construir, não só como construir.
  • Delegar pra IA é a mesma decisão de delegar pra um colaborador. A questão não é "devo usar IA?" — é "o que faz sentido eu continuar fazendo eu mesmo?".
📺 Cursos / Vídeos
  • grátis Asimov Academy — módulo de IA Generativa (fonte principal)
  • grátis Andrej Karpathy — "Intro to LLMs" (YouTube, ~1h)
  • grátis Andrej Karpathy — "Let's build GPT from scratch" (YouTube)
  • grátis DeepLearning.AI — "Generative AI for Everyone" (Coursera, audit gratuito)
📚 Leitura
  • grátis Artigo original "Attention Is All You Need" (arXiv)
  • grátis Documentação Hugging Face — NLP Course (huggingface.co/learn)
  • ~US$15 Livro "Build a Large Language Model from Scratch" — Sebastian Raschka
🛠️ Prática
  • Rodar Ollama localmente com LLaMA 3 ou Mistral — brincar com temperatura, top-k
  • LM Studio para comparar modelos no próprio PC
  • Hugging Face Spaces — explorar demos de modelos multimodais
Dica: Não tente entender TUDO de matemática por trás. Foco nos conceitos: como tokens são gerados, o que é temperatura, como embeddings representam semântica. Isso já te dá base pra todo o resto.

Prompt Engineering
CoT few-shot ReAct grátis disponível
›
📝 Anotações
  • Testar em modelos locais menores foi a melhor decisão deste módulo. Deixa muito claro o que é técnica de prompt e o que é capacidade do modelo — nos modelos grandes essa distinção fica mascarada.
  • ReAct foi o experimento mais revelador. Ver um modelo pequeno expandir sua capacidade real através de raciocínio + ação deixou claro por que isso importa em aplicações.
  • Prompt engineering não é só pra usar Claude ou ChatGPT no dia a dia — é a base de qualquer aplicação que chama uma LLM.
  • Construir bem um prompt é estender sua capacidade de produção. Não é atalho, é alavanca — e tem limite onde começa o fine-tuning.
📺 Cursos
  • grátis Asimov Academy — módulo de Prompt Engineering (fonte principal)
  • grátis DeepLearning.AI — "ChatGPT Prompt Engineering for Developers" (com Andrew Ng)
  • grátis Anthropic — Guia oficial de Prompt Engineering (docs.anthropic.com)
  • grátis Learnprompting.org — guia completo e gratuito
📚 Leitura
  • grátis Artigo "Chain-of-Thought Prompting Elicits Reasoning in LLMs" (arXiv)
  • grátis Artigo "ReAct: Synergizing Reasoning and Acting in LLMs" (arXiv)
  • grátis OpenAI Cookbook (github.com/openai/openai-cookbook)
Dica: Crie um repositório no GitHub com seus prompts organizados por tipo. Já vai construindo portfólio desde o módulo 2.
